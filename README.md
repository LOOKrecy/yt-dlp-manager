# Local yt-dlp Manager

## Описание

Local yt-dlp Manager — локальное Windows-приложение с браузерным интерфейсом для управления `yt-dlp.exe` без ручного ввода команд. Backend запускается на FastAPI и слушает только `127.0.0.1`, frontend сделан на обычных HTML/CSS/JavaScript.

## Изолированная среда Python

Проект использует полностью изолированное локальное виртуальное окружение Python в папке:

```text
.venv/
```

`start.bat` создаёт эту папку внутри корня проекта, если она отсутствует, и затем использует только:

```text
.venv\Scripts\python.exe
.venv\Scripts\pip.exe
```

Зависимости устанавливаются только внутрь `.venv`. Глобальные `site-packages` Python не используются, глобальная установка пакетов не выполняется, и другие Python-приложения на компьютере не затрагиваются.

Пользователю не нужно вручную активировать виртуальное окружение: запускайте приложение только через `start.bat`.

Если окружение нужно пересоздать, удалите папку `.venv` и снова запустите `start.bat`. Также можно запустить `reset_venv.bat`, который удалит и пересоздаст только локальное окружение `.venv`, не изменяя глобальную установку Python.

## Требования

- Windows.
- Python 3.11 или новее, доступный как `python` в PATH.
- `yt-dlp.exe` в папке `bin/`.
- `ffmpeg.exe` и `ffprobe.exe` в папке `bin/` для объединения потоков, аудио и фрагментов.
- `deno.exe` в папке `bin/` или Deno в PATH — опционально, но рекомендуется для YouTube, где yt-dlp может выполнять JavaScript.

## Структура проекта

```text
app/                 Backend и static frontend
app/static/          index.html, styles.css, app.js
bin/                 yt-dlp.exe, ffmpeg.exe, ffprobe.exe, deno.exe (опционально)
Downloads/           Папка загрузок по умолчанию
data/                config.json и history.json
logs/                Логи заданий
.venv/               Локальное виртуальное окружение Python, создаётся автоматически
requirements.txt     Минимальные Python-зависимости приложения
start.bat            Запуск на Windows с автоматической подготовкой .venv
reset_venv.bat       Необязательный сброс и пересоздание .venv
```

## Первый запуск

1. Установите Python 3.11+.
2. Скопируйте `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` в папку `bin/`. Для YouTube рекомендуется также положить туда `deno.exe`.
3. Запустите `start.bat` двойным кликом.
4. Скрипт определит корень проекта, создаст `.venv` при необходимости, обновит `pip` внутри `.venv`, установит зависимости через `.venv\Scripts\pip.exe` и откроет `http://127.0.0.1:8765`.
5. Backend запускается только через `.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765`.

## Обновление или восстановление зависимостей

Обычно ничего делать не нужно: `start.bat` проверяет локальное окружение и устанавливает зависимости в `.venv` автоматически.

Если локальное окружение повреждено или вы хотите полностью пересоздать зависимости:

1. Закройте запущенное приложение.
2. Удалите папку `.venv` и снова запустите `start.bat`.
3. Или запустите `reset_venv.bat`, чтобы удалить `.venv`, создать его заново и переустановить зависимости.

Оба способа затрагивают только папку `.venv` внутри проекта и не устанавливают пакеты глобально.

## Где взять и куда положить yt-dlp.exe

Взять тут: (https://github.com/yt-dlp/yt-dlp/releases/latest)

Положить файл сюда:

```text
bin/yt-dlp.exe
```

Если файл отсутствует, приложение не упадёт, но покажет статус `Not found`, а запрос форматов и загрузка вернут понятную ошибку.

## Где взять и куда положить ffmpeg.exe
Взять тут: (https://github.com/BtbN/FFmpeg-Builds/releases/latest)

Положить файлы сюда:

```text
bin/ffmpeg.exe
bin/ffprobe.exe
```

`ffmpeg.exe` особенно важен для фрагментов, объединения видео/аудио и извлечения аудио.

## Где взять и куда положить Deno для YouTube

Для некоторых YouTube-сценариев `yt-dlp` может использовать JavaScript runtime. Самый компактный вариант для portable-сборки — скачать официальный `deno.exe` и положить его рядом с остальными инструментами:
Взять тут: (https://github.com/denoland/deno/releases/latest)

```text
bin/deno.exe
```

Если `bin/deno.exe` найден, приложение покажет его статус во вкладке “Настройки”. В команды `yt-dlp` Deno добавляется только при включённой опции “Использовать Deno” в разделе “Доступ”; если файла нет в `bin/`, приложение попробует найти `deno` в `PATH`.

## Как пользоваться

1. Откройте вкладку “Загрузка”.
2. Вставьте URL.
3. Выберите режим загрузки: лучшее видео+аудио, только видео, только аудио или пользовательский выбор.
4. При необходимости включите proxy, cookies, Deno, фрагмент или impersonate.
5. Нажмите “Запросить форматы” для принудительного обновления списка или “Выбрать из полученного списка”, если форматы для этой же ссылки уже запрашивались. Форматы откроются во всплывающем окне без переключения вкладки.
6. Если ожидаемый файл уже существует, выберите “Переименовать новый файл”, “Перезаписать старый” или “Отмена”.
7. Следите за процессом во вкладке “Логи” или по верхним техническим сообщениям.
8. После завершения откройте результат кнопкой “Показать результат” во всплывающем окне или через вкладку “Результат”.

## Как запросить форматы

Введите URL и нажмите “Запросить форматы”. Backend выполнит безопасную команду вида:

```text
bin/yt-dlp.exe -F [access args] [extra args] URL
```

Команда запускается через `subprocess` списком аргументов и `shell=False`. Полученный список хранится в браузере для текущего набора URL/настроек доступа, поэтому повторный выбор можно открыть без нового запроса кнопкой “Выбрать из полученного списка”; кнопка “Запросить форматы” всегда обновляет список принудительно.

## Как скачать видео

Выберите режим “Лучшее качество видео+аудио”. Приложение передаст формат:

```text
-f bestvideo+bestaudio/best
```

Для режима “Только видео” приложение передаст:

```text
-f bestvideo
```

В режиме “Пользовательский выбор” в окне форматов можно отдельно нажать “Видео” и “Аудио”; итоговое поле `-f` будет заполнено, например, как `137+140`. Если выбран готовый формат со звуком, аудио можно не выбирать.

## Как скачать только аудио

Выберите режим “Только аудио” и аудиоформат `m4a`, `mp3`, `opus` или `wav`. Приложение передаст:

```text
-x --audio-format <format>
```

## Как использовать proxy

Включите “Использовать proxy” и укажите адрес, например:

```text
socks5://127.0.0.1:1080
```

Если галка включена, но строка пустая, запуск будет заблокирован.

## Как использовать cookies

Включите “Использовать cookies-файл” и укажите путь к cookies-файлу. Backend проверит существование файла перед запуском.

## Как скачать фрагмент

Включите “Скачать только фрагмент” и укажите начало/конец в формате `HH:MM:SS`, например:

```text
00:01:15 — 00:02:40
```

Приложение сформирует аргумент:

```text
--download-sections "*00:01:15-00:02:40"
```

Для этой функции нужен `bin/ffmpeg.exe`.

## Где хранятся настройки

Настройки сохраняются в:

```text
data/config.json
```

Файл создаётся автоматически при первом запуске.

## Где хранятся загрузки

По умолчанию загрузки сохраняются в:

```text
Downloads/
```

Можно указать другую папку во вкладке “Загрузка”. Приложение создаёт папку при необходимости и проверяет запись.

## Известные ограничения

- Приложение рассчитано на локальный запуск на Windows.
- Выбор файла/папки реализован как текстовый путь, потому что браузер не может свободно выбирать произвольные локальные пути для backend без дополнительных системных интеграций.
- Точный прогресс зависит от формата вывода `yt-dlp`; текущая версия показывает потоковые логи и статус процесса.
- Предпросмотр в браузере доступен только для форматов, поддерживаемых браузером.
