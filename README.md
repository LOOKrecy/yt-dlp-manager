# yt-dlp Manager

## Описание

`yt-dlp Manager` — локальное веб-приложение для запуска `yt-dlp` через простой интерфейс в браузере.

Проект состоит из FastAPI backend и статического frontend на Vanilla JS. Приложение предназначено для работы только на локальном компьютере и по умолчанию должно открываться по адресу:

```text
http://127.0.0.1:8765
```

Через интерфейс можно сохранить настройки, запросить доступные форматы, запустить загрузку видео или аудио, передать proxy/cookies, скачать фрагмент, посмотреть логи и историю запусков.

## Требования

- Python 3.10+.
- Установленные Python-зависимости из `requirements.txt`.
- `yt-dlp.exe`, размещенный в `bin/yt-dlp.exe`.
- Для объединения потоков, конвертации аудио, миниатюр и части операций постобработки нужен `ffmpeg.exe` в `bin/ffmpeg.exe`.
- Для некоторых проверок и операций `yt-dlp` также может использовать `ffprobe.exe` в `bin/ffprobe.exe`.
- Windows поддерживается через `start.bat`; на Linux/macOS приложение можно запускать командой `python -m uvicorn ...`.

```text
yt-dlp-manager/
```

Runtime-файлы приложения должны находиться в `Downloads/`, `data/` и `logs/`.

## Первый запуск

1. Перейдите в корень проекта.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Положите исполняемые файлы в `bin/`:
   - `bin/yt-dlp.exe`
   - `bin/ffmpeg.exe`
   - желательно `bin/ffprobe.exe`

4. Запустите приложение:

   ```bash
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
   ```

   На Windows можно использовать:

   ```bat
   start.bat
   ```

5. Откройте в браузере:

   ```text
   http://127.0.0.1:8765
   ```

Приложение должно оставаться localhost-only: не меняйте host на `0.0.0.0`, если это не было явно запрошено.

## Куда положить yt-dlp.exe

Положите `yt-dlp.exe` в папку `bin/` в корне проекта:

```text
bin/yt-dlp.exe
```

Именно этот путь проверяется приложением при диагностике окружения и используется для команд `yt-dlp`.

## Куда положить ffmpeg.exe

Положите `ffmpeg.exe` в папку `bin/` в корне проекта:

```text
bin/ffmpeg.exe
```

Также рекомендуется положить рядом `ffprobe.exe`:

```text
bin/ffprobe.exe
```

`ffmpeg` нужен для объединения видео и аудио, извлечения аудио, конвертации, встраивания метаданных/миниатюр и других операций постобработки.

## Как пользоваться

1. Запустите backend и откройте `http://127.0.0.1:8765`.
2. На основной вкладке вставьте URL видео или плейлиста.
3. Выберите режим загрузки:
   - видео;
   - видео + аудио;
   - только аудио.
4. При необходимости настройте формат, папку загрузки, шаблон имени файла, субтитры, proxy, cookies, фрагмент или диапазон плейлиста.
5. Нажмите кнопку получения форматов или запуска загрузки.
6. Смотрите прогресс во вкладке логов.
7. История запусков доступна во вкладке истории.

## Как запросить форматы

1. Вставьте URL в поле адреса.
2. Нажмите кнопку «Получить форматы» или откройте вкладку форматов и нажмите «Обновить».
3. Backend вызовет `yt-dlp` для получения списка форматов.
4. В таблице появятся `format code`, расширение, разрешение и примечание.
5. Скопируйте нужный `format code` или выберите его в настройках формата, если интерфейс предлагает такой выбор.

API-запрос выполняется через endpoint:

```text
POST /api/formats
```

## Как скачать видео

1. Вставьте URL.
2. Установите режим загрузки видео.
3. Выберите качество:
   - `best` для лучшего доступного варианта;
   - `worst` для минимального варианта;
   - конкретный `format code`, полученный через список форматов.
4. Проверьте папку загрузки. По умолчанию используется `Downloads/`.
5. Нажмите кнопку загрузки.
6. Лог процесса появится в `logs/`, а запись о запуске — в истории.

API-запрос выполняется через endpoint:

```text
POST /api/download
```

## Как скачать только аудио

1. Вставьте URL.
2. Выберите режим `audio` / «только аудио».
3. Выберите аудиоформат, например `mp3`.
4. Убедитесь, что `ffmpeg.exe` находится в `bin/ffmpeg.exe`, иначе извлечение и конвертация аудио могут не выполниться.
5. Запустите загрузку.

В этом режиме приложение передает `yt-dlp` аргументы извлечения аудио и выбранный аудиоформат.

## Как использовать proxy

1. Откройте настройки proxy.
2. Включите proxy.
3. Укажите proxy URL, например:

   ```text
   http://127.0.0.1:8080
   ```

4. Сохраните настройки или запустите загрузку с включенным proxy.

При включенном proxy backend добавляет к команде `yt-dlp` аргументы:

```text
--proxy <proxy_url>
```

## Как использовать cookies

1. Подготовьте файл cookies в формате, который понимает `yt-dlp`.
2. Положите файл в удобное локальное место, например:

   ```text
   data/cookies.txt
   ```

3. В настройках включите cookies.
4. Укажите путь к файлу cookies.
5. Запустите запрос форматов или загрузку.

Если указан относительный путь, он считается относительно корня проекта. Файл должен существовать, иначе backend вернет ошибку.

При включенных cookies backend добавляет к команде `yt-dlp` аргументы:

```text
--cookies <cookies_file>
```

## Как скачать фрагмент

1. Включите опцию скачивания фрагмента / section.
2. Укажите время начала и/или конца, например:

   ```text
   00:00:10
   00:01:30
   ```

3. Запустите загрузку.

Для фрагмента backend использует аргумент `yt-dlp`:

```text
--download-sections *<start>-<end>
```

Пример диапазона: `*00:00:10-00:01:30`.

## Где хранятся настройки

Настройки интерфейса хранятся в JSON-файле:

```text
data/config.json
```

Если файл отсутствует или поврежден, приложение использует значения по умолчанию и может создать файл заново.

## Где хранятся загрузки

По умолчанию файлы скачиваются в:

```text
Downloads/
```

Папку можно изменить в интерфейсе через поле директории загрузки. Относительный путь считается относительно корня проекта.

Логи запусков хранятся в:

```text
logs/
```

История запусков хранится в:

```text
data/history.json
```

## Известные ограничения

- Приложение рассчитано на локальное использование и по умолчанию должно слушать только `127.0.0.1:8765`.
- Одновременно управляется только один процесс загрузки `yt-dlp`.
- Для некоторых операций обязателен `ffmpeg.exe`; без него объединение потоков, извлечение аудио и постобработка могут завершиться ошибкой.
- `yt-dlp.exe`, `ffmpeg.exe` и `ffprobe.exe` не входят в проект и должны быть добавлены пользователем в `bin/`.
- Доступность форматов зависит от сайта, URL, региона, cookies, proxy и текущего поведения `yt-dlp`.
- Cookies-файл должен уже существовать на диске.
- История фиксирует запуск и базовые параметры, но не является полноценной очередью задач.
- Приложение не использует Docker, Node.js, React, Vue, Angular или Gradio.
